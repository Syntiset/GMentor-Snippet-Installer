# Сниппеты — структура и ручная установка

Исходники всех расширений, разложенные по способу применения. Папка из трёх подпапок:

| Папка | Что внутри | Как ставится |
|---|---|---|
| [`custom/`](./custom/) | сниппеты для **кастомных листов** (входят в bundle) | через GSI (вкладка «Кастомные листы») **или** вручную в `SCRIPT` и `CSS/LESS` листа |
| [`all/`](./all/) | сниппеты для **любого листа** персонажа (фиксы, хоумрулы) | через GSI (вкладка «Все листы») — в браузер, для ручной вставки придётся переписывать |
| [`board/`](./board/) | инструменты **мастерских досок** | через GSI (вкладка «Доски») — в браузер, не ручной вставкой |

> [!NOTE]
> Общий обзор, способы установки (браузерный плагин, Windows/Linux-приложение) — в [главном README](../README.md). Ниже подробно про **ручную** установку `custom/`; всё из `all/` и `board/` ставится через GSI в один клик, про их перечень — справочно в конце.

## `custom/` — для кастомных листов

`.js`-сниппеты для прямой вставки в `SCRIPT`, `.less` — в `CSS / LESS`. Альтернатива плагину/приложению, когда нужен полный контроль или поставить только часть функционала на пару-тройку листов.

|---|---|---|---|

### LESS-стили

| Файл | Когда нужен |
|---|---|
| [`gc-utils.less`](./custom/gc-utils.less) | Всегда — скрывает base64-теги. |
| [`gc-toggler.less`](./custom/gc-toggler.less) | Если используется toggler-UI. |
| [`hit-locations.less`](./custom/hit-locations.less) | Если используется hit-locations. |
| [`dmg-scale.less`](./custom/dmg-scale.less) | Никогда, это всего лишь заглушка. |
| [`cf-mod.less`](./custom/cf-mod.less) | Если используется cf-mod. |
| [`spell-attr.less`](./custom/spell-attr.less) | Если используется spell-attr. |

### Порядок подключения

**Важно!** Системные первыми (`gc-toggler` → `gc-utils`), затем `fix-multiply-zero`, цепочка зон `hit-locations` → `dr-inheritance`, после неё независимые (`strong-back`, `dmg-scale`, `cf-mod`, `spell-attr`, `ace-fold-all`), а `gc-toggler-ui` — последним. Это тот же порядок, в котором собран bundle.

### Как ставить

1. На кастомном листе справа кликнуть `</>` → открыть `CSS/LESS` или `SCRIPT` редактор.
2. **Если в редакторе уже есть код** — добавлять новые сниппеты в конец, каждый — внутри своей IIFE `(function(){ ... })();`.
3. Скопировать содержимое нужных `.js` файлов (целиком, включая IIFE) и вставить в редактор.
4. Клик по `СОХРАНИТЬ`.
5. Для стилей — `CSS/LESS` → аналогично вставить нужные `.less`.

### Пример: минимальный набор для зон попаданий

`gc-toggler.js` + `gc-toggler.less`, `gc-utils.js` + `gc-utils.less`, `fix-multiply-zero.js`, `hit-locations.js` + `hit-locations.less`, `dr-inheritance.js`.
Опционально: `gc-toggler-ui.js`.

### Обновление / откат

- **Обновление:** в редакторе найти старую копию сниппета (по заголовку-комментарию или namespace `window.gcInternal.patched.*`), заменить блок новым содержимым. Все сниппеты идемпотентны (guard на повторный eval).
- **Откат:** удалить IIFE сниппета целиком → сохранить → обновить страницу. Или через UI «Сниппеты» снять чекбокс группы (сниппет остаётся в коде, но не активируется).

## `all/` — для любого листа персонажа

Ставятся через **GSI** (вкладка «Все листы») — кешируются в браузере и работают на любом листе. Для ручного перевода в кастомный лист придётся грубо работать напильником.

| Файл | Что делает | Категория |
|---|---|---|
| `snippets-hub.js` | Опциональный, но рекомендуемый хаб: собирает установленные сниппеты из настроек листа в одну секцию-менюшку. | Служебное |
| `sub-location.js` | Допбросок 1d6 на подлокацию при попадании в руки, ноги и т.д.. | Фича |
| `perdie.js` | Багфикс урона «за куб» (Weapon Master / All-Out Attack) от базового Thrust/Swing. | Фикс |
| `ranged-wm.js` | Отображение опции «Мастер оружия» в дистанционной атаке. | Фикс |
| `kyos-full.js` | Полная поддержка KYOS: стоимость ST/HP + отключение подсвета HP; опц. цена Lifting/Striking ST (7/1 за ур.). | Фикс |
| `cr-mod.js` | Автоматический учёт штрафов самоконтроля от активных состояний. | Фича |
| `alt-cut.js` | Альтернативная таблица swing-урона (основанно по [No School Grognard](https://noschoolgrognard.blogspot.com/2013/04/adjusting-swing-damage-in-dungeon.html), +1 за 2 ST). | Хоумбрю |

Манифест — [`all/_manifest.json`](./all/_manifest.json).

## `board/` — инструменты мастерских досок

Ставятся **только через GSI** (вкладка «Доски») в выбранные доски.

| Файл | Что делает |
|---|---|
| `initiative-tracker.js` | Трекер инициативы: плавающая панелька, импорт персонажей с доски, синхронизация. |
| `char-view-mode.js` | Режимы отображения персонажей на доске (полный / аватар / аватар+имя). |

Манифест — [`board/_manifest.json`](./board/_manifest.json).
